# FIFO verification workspace

Use the verification MCP tools to inspect the SV, UVM and Formal profiles, submit native jobs, and read the corresponding evidence. A run ID identifies a real job. Quote its actual status and evidence when reporting a result.

The requirements are in SPEC.md and their test and property links are in verify.yaml. The mutant variant changes the simultaneous read/write occupancy update for acceptance testing. A normal run is the baseline for stage completion.
